How someone becomes admin

  1. The first person to sign in to a new deployment — that was you.
  2. An admin sets their role to admin above. Add them first if they have not signed in yet.
  3. Their address is in the ADMIN_EMAILS environment variable, which always wins: {% if admin_emails %}{{ admin_emails|join(', ') }}{% else %}currently empty{% endif %}. Useful as a way back in if the last admin role is ever lost.
